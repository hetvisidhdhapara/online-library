
# Readify – Online Library Management System

Readify is a web-based library platform where students can explore books, read PDF materials online, save their favorite books, and share reviews and ratings.

## Features

### Admin
- Admin Login
- Admin Dashboard
- Add and Manage Books
- Upload PDF Books
- Manage Students
- Admin Profile Management
- Export Students and Books Data

### Student
- Student Registration and Login
- Student Dashboard
- Browse and Search Books
- Read Books Online
- Favorite Books
- Reading History
- Book Reviews and Ratings
- Student Profile Management

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP

## Installation

1. Install XAMPP.
2. Copy the project folder into `htdocs`.
3. Start Apache and MySQL.
4. Create a database named `readify_db` in phpMyAdmin.
5. Import the project's database tables.
6. Update database settings in `config/db.php` if required.
7. Open the project in your browser:

   http://localhost/online-library/

## Project Purpose

This project was developed to practice PHP, MySQL, database management, web development, and practical software development skills.
